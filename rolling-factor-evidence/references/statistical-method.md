# 统计方法

## 日期内证据

所有计算先在 `pool_id × decision_time` 内完成，再对决策期等权汇总。

- 连续因子使用平均百分位秩；相同值不得按证券代码、行号或随机数拆开。
- 序数因子按原始档位；档位过多时使用与连续因子相同的平均秩分组。
- 二元因子只比较 1 与 0。
- 无序类别因子不编码成有序数，首版不产生经济资格。
- RankIC 是因子秩与同周期标签秩的 Spearman 相关。
- Spread 是最高组平均标签减最低组平均标签。

组数在计划阶段根据候选池结构冻结：优先五组；若结构上无法保证每组最小样本，则降为三组；再不可行则该计划行没有可执行分组。实际日期因并列、缺失或标签无效导致端点组不全时，该日期退出并记录唯一原因。

## 有效期和覆盖

理论决策期只要求候选池存在。实际有效期还要求标签成熟、因子覆盖、足够不同值、所需组齐全和组内样本量合格。

```text
required_valid = min(
    valid_decision_cap,
    max(minimum_valid_decisions,
        ceil(valid_decision_coverage * theoretical_decisions))
)
```

若理论期少于 `minimum_valid_decisions`，结论是样本不足，不降低门槛。

## HAC 与 BH

对按决策时点排序的主指标序列计算 Bartlett 权重 Newey-West 长期方差。缺失决策期删除，不补零。`lag >= sample_size`、负长期方差或零标准误均不可检验。

双侧 p 值和置信区间使用预注册置信度下的正态近似。主结果只用主滞后；敏感性滞后单独输出。

BH family 是同一 deployment、recipe、pool、label 和主指标下的全部可检验因子。RankIC 与 spread 不同时进入主 family。多窗口分别控制各自 family；窗口共识不宣称拥有跨窗口整体 FDR 保证。

## 方向、经济幅度和稳定性

方向是主指标历史均值的符号。统计检验始终双侧；方向只用于把后续解释统一为越大越好。

经济门槛使用方向调整后 spread 的 HAC 置信区间下界：

```text
economic_pass = adjusted_spread_lower_ci >= minimum_effect
```

稳定性按决策年份汇总，要求正向年份占比达到门槛。连续和序数因子还要求方向调整后的平均单调性达到门槛；二元因子不设置伪单调性。

`model_candidate` 只要求 PIT、覆盖、有效决策期和池内变化合格。`economic_eligible` 还要求 q 值、经济幅度和稳定性全部合格。

## 暴露诊断

- 连续暴露：逐决策期计算池内 Spearman 相关，再报告均值、中位数、绝对值均值和有效期数。
- 类别暴露：逐决策期用因子秩对类别哑变量回归，报告调整 R²；缺失类别统一为 `UNKNOWN`。

暴露诊断默认不改变入选结论。若项目要把中性化设为硬门槛，应作为新的预注册研究版本，而不是看到结果后切换。
