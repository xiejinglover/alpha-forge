# 异构仓库适配指南

## 定位顺序

先读取仓库指令、README、数据字典和配置，再定位：

1. 实际候选池生成入口；
2. 信号或调仓日历；
3. PIT 因子读取入口及版本时间；
4. 正式标签、入场、退出、顺延和成本逻辑；
5. 行业和风格暴露的 PIT 来源。

不要从回测结果倒推标签，不要用当前成分回填历史候选池，不要把财务报告期当作可获得时间。

## 转换要求

- 转换器只做字段映射、类型规范化和稳定 ID 生成。
- 标签值必须由目标仓库正式执行路径产生；本 Skill 不重新实现交易引擎。
- 若仓库只能给出理论 `t+H` 收益而无法证明与正式执行一致，将结果标记为诊断，不能运行正式筛选。
- 一个 observation 的 ID 应由池、决策时点和标的稳定字段生成，不包含因子值或标签值。
- 长表可按部署期分片，但所有分片必须共享相同元数据和时区。

## 大数据

CSV 是基线互操作格式。数据量较大时可以用 Parquet 适配器，但运行环境必须提供 Parquet 引擎，且转换后列语义、唯一键和哈希规则不变。不要为了节省空间丢弃因子缺失行；候选池分母来自 observations，因子长表可以省略缺失值记录。
