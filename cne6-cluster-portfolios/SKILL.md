# CNE6 风格分簇策略组合

以目标策略仓库为事实来源，复用已有候选预测、原生选股、正式账户及回测入口。先读 [方法与参数](references/methodology.md)；定位风险数据时读 [数据来源](references/data-sources.md)。不将技能文档视为已经提供通用计算程序。

## 1. 确认输入与冻结规格

定位稳定的策略 ID、股票 ID、预测分数及方向、信号日、调仓日、正式扣费账户收益、原生选股数量、交易日历和基准。完整池模式必须有完整预测，TopN 缓存不能反推出完整池。

显式区分原生选股数量、`input_top_n` 和 `output_top_n`。未指定两个 TopN 时使用同类型策略的原生数量；若原生数量不统一且无法从任务确定，先澄清。不固定为 3。

在读取部署期表现前保存候选集合、数据版本、训练与部署窗口、证据身份、因子、簇数、代表方法和数量、组合模式、权重与缺失规则。默认过去三年训练、年度更新、下一年冻结；历史已消费区间不能重新命名为未使用留出集。

## 2. 从原生选股计算暴露并分簇

默认用每日原生选股的等权个股暴露构造策略暴露，按有效日聚合训练窗口。完整预测池组合不自动改变聚类暴露来源。使用八个默认风格及训练期因子收益协方差转换，执行六簇 KMeans；具体公式、参数和可调门槛见方法文档。

先检查个股暴露、因子收益的字段、单位、覆盖及可得性。不得以策略收益回归系数代替持仓暴露，不得以其他技能内置因子收益代替个股暴露。无法验证历史可得性时明确标记研究限制，不声明已满足严格 PIT。

## 3. 选择每簇代表

支持总距离中心性（历史 R1/R3/R10）、全部合格成员（RC）、训练期共识重合（RT）和年度位置稳定性（RS）。默认总距离法、每簇 1 个；代表数可以是统一整数或逐簇映射。保留实际评分和选中数量。

区分历史已执行设置与通用扩展。R3/R10 是中心性排序前若干名，不是联合多个 medoid 优化；RT/RS 多代表是扩展。不得根据部署期收益换代表或追加筛选。

## 4. 聚合股票并复用正式账户

默认簇等权、簇内代表等权。可选用训练期簇账户收益估计风险平价；权重在部署前冻结。

- `top_n_vote`：代表各提交前 `input_top_n`，每只股票累加代表权重，按票数取前 `output_top_n`。
- `full_pool_mean_rank`：各代表在共同有效完整预测池内排名，按代表权重计算平均名次，取最小的前 `output_top_n`。不得退化为全池每股一票。

默认第一种模式、最终股票等权；票数归一化持仓只适用于第一种。明确展示平均名次模式为此次通用扩展，不声称历史 EMA20 已验证。

保留完整股票分数、排序和最终目标权重，将其交给已有正式单账户入口，沿用信号与成交时序、费用和交易限制。线性账户收益只用于权重估计或诊断，不能冒充股票组合正式回测。缺失与并列按方法文档处理，不静默替换策略或回填信号。

## 5. 交付可追溯结果

保存冻结规格、输入路径及哈希、覆盖与排除原因、各批次暴露/协方差/标签、代表评分与权重、日度投票或平均名次、目标持仓、正式运行 ID 和结果。

报告总体结论、各配置收益与风险、换手、持仓数、覆盖变化、簇及代表稳定性、相对原生基准的表现和证据限制。用户要求的配置全部展示，不按诊断期赢家晋级。仅凭风格分簇不能断言已消除家族共同风险。

若必需数据或正式执行入口缺失，给出明确适配缺口；不得重训模型、虚构暴露或使用简化回测补齐结果。
