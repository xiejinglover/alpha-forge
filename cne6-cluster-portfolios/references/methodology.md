# 方法、参数与手算示例

## 参数与时间

默认对部署年 Y 使用 Y-3 至 Y-1，全年冻结标签、代表和策略权重。窗口、部署频率与下述参数可配置，但在评估期结果可见前固定；调整频率时必须明确每个训练截止日和部署起止日。

| 参数 | 默认与含义 |
|---|---|
| `factors` | beta、size、momentum、book_to_price、residual_volatility、liquidity、profitability、investment_quality，固定顺序 |
| `n_clusters` | 6，正整数 |
| `selection_method` | `total_distance`；另有 `all_members`、`consensus_overlap`、`stable_position` |
| `representatives_per_cluster` | 1；支持正整数或当前批次完整簇 ID → 正整数映射，RC 不使用此参数 |
| `input_top_n` / `output_top_n` | 各自独立的正整数；未提供则各自取同类型策略原生选股数量 |
| `consensus_top_n` | 默认原生选股数量，用于 RT；与组合输出数量分离 |
| `stable_lambda` | 1，非负数 |
| `combination_mode` | `top_n_vote` 或 `full_pool_mean_rank`，默认前者 |
| `cluster_weighting` | `equal` 或 `risk_parity`，默认前者 |
| `stock_weighting` | `equal`；TopN 投票还支持 `normalized_votes` |
| 资格条件 | 训练期账户复合收益 > 0、年化波动 ≤ 候选截面 90% 分位、暴露覆盖率 ≥ 95%、完整训练年份 |

默认候选为同类型策略。资格条件可改，但须记录精确口径。收益完整性先于收益/波动筛选；波动分位在收益完整候选中计算。原生数量可因候选而异，按其原生配置计算暴露，不把组合 TopN 强加给聚类输入。

策略 ID、证券 ID 均使用稳定字符串。簇标签只在当前批次有意义，不能把 KMeans 的同号标签当跨年同一经济簇；逐簇数量映射须明确对应批次，不可用部署表现给簇重新命名。

## 暴露、风险距离与分簇

设候选 c 的原生选股集合为 H(c,t)，K(c,t) 是原生配置应有数量，x(i,t) 为八维个股暴露。默认只保留原生选股完整且所有股票全部所需字段有效的信号日：

`e(c,t) = sum(x(i,t), i in H(c,t)) / K(c,t)`。

以应有信号日为分母计算覆盖率；不要删掉缺失日期后再算覆盖。年度暴露为有效日算术平均，窗口暴露按各年度有效日数加权。默认三年均有有效数据；训练期收益使用同一完整账户日历，不因暴露缺失改写账户收益。

在训练期共同日历上，以相同字段顺序的日因子收益估计 `Sigma = 252 × LedoitWolf(factor_returns).covariance_`。特征分解构造对称平方根 L，历史实现将特征值下限设为 `1e-16`。候选坐标 `z(c) = e(c) L`，平方距离为 `(e(a)-e(b)) Sigma (e(a)-e(b))'`。这不是逆协方差白化，也不额外对候选截面 z-score。

执行 KMeans++，默认 `n_init=50, random_state=2026, n_clusters=6`，记录依赖版本。合格候选或不同风险坐标不足簇数、出现空簇时停止该批次并报告；不静默降低簇数。随机种子与暴露扰动可作为预注册稳健性检查，不能依部署收益选 seed。

## 六种历史设置与通用代表规则

| 历史设置 | 通用规则与公式 | 历史边界 |
|---|---|---|
| R1 | `D(c)=sum_j ||z(c)-z(j)||`，j 遍历同簇全部合格成员；取 D 最小者 | 精确 medoid |
| R3 | 按 D 升序取前三名 | 不是联合多 medoid 优化 |
| R10 | 按 D 升序取前十名 | 与 R1/R3 同一个排序 |
| RC | 所有合格成员参与，每簇总预算相同 | 历史为日度 Top3 共识 |
| RT | 取训练期与簇内共识选股重合度最高者 | 历史 Top3、每簇一个 |
| RS | 取年度风格位置分数最低者 | 历史 λ=1、每簇一个 |

RT：训练日内按簇内成员原生选股的等权出现次数形成共识，按票数降序、股票 ID 升序取 `consensus_top_n`。对候选计算 `sum_t |H(c,t) ∩ consensus(t)| / sum_t |H(c,t)|`；固定原生 N 时等于每日重合比例平均，不是 Jaccard。历史实现允许日内可用成员形成共识并记录可用数；通用默认用簇内全部成员共同有效训练信号日，避免成员评分日期不同，显式标记此差异，严格复现历史时沿用历史日历。

RS：每个训练年以该批次 L 转换年度暴露，计算到该年当前簇成员坐标均值的欧氏距离。簇内以平均秩计算距离百分位 `rank / member_count`；跨年分数为 `median(percentile) + stable_lambda × std(percentile, ddof=1)`。只有一个年度时标准差记 0。它使用年度中心距离，不是把年度总距离直接相加。

三种有评分方法均以自身分数方向优先，并列时训练期 Sharpe 降序、候选 ID 升序。非有限评分或 Sharpe 不可进入代表排序。各簇取请求数量与实际人数的较小值并记录；默认按实际人数分配权重。RT/RS 多代表、RC 接完整池平均名次、不同 N 以及完整池排名模式均属于通用扩展，不写成历史已验证方案。

## 策略预算与股票聚合

设簇预算 q(g)，选中成员数 m(g)，每个代表权重 `w(c)=q(g)/m(g)`。默认 q(g)=1/G，即使各簇人数不同也不让大簇多占预算。RC 的 m(g) 是全部合格成员数。

风险平价：先以选中成员正式扣费日收益等权形成各簇训练期线性账户收益，使用共同完整日历和 LedoitWolf 协方差 C。最小化 `sum_g [q(g)(Cq)(g) - q'Cq/G]^2`，约束 `sum(q)=1, 0.5/G ≤ q(g) ≤ 2/G`。从等权起点使用 SLSQP，历史 `ftol=1e-18, maxiter=2000`；失败或约束不满足时明确记录 `equal_fallback` 并回退等权，不能仍标风险平价成功。单代表对应原始实现，多代表簇收益是推广。

TopN 投票：预测分数统一为越大越好，每策略按分数降序、股票 ID 升序截取输入 N。同一策略每日同一股票只计一次，重复键先报错。`V(i)=sum_c w(c) × 1[i in TopN(c)]`。票数降序、股票 ID 升序取输出 N。策略提交数量相同时无需额外归一化；若数量不足则保留实际数量并记录，每股仍获 w(c)，不静默改成每策略固定总票数。最终等权，或在选中股票内用 `V(i)/sum_selected V`。

完整池平均名次：每个调仓日先求所有代表有限预测股票集合的交集 U，在 U 内分别重新排序，最好为第 1 名。`R(i)=sum_c w(c) rank_c(i) / sum_c w(c)`，按 R 升序、股票 ID 升序选输出 N，最终等权。记录各原始池大小、交集大小和保留比例；不对原始不同股票池的名次直接求平均，不用预测分数平均替代名次平均。

两种模式均只使用当时可得信号。若任一代表整日无有效预测，或完整池交集为空，不重分代表预算、不自行创建目标仓位；该日标记不可构建，交已有账户引擎按其已记录缺失信号规则处理。规则不明则停止正式回测并报告。股票数少于输出 N 时只持有有效股票并重新归一化目标权重。目标权重不保证实际成交；停牌、涨跌停、现金及费用由原引擎处理。

## 可复核手算例

1. 两簇预算各 1/2，第一簇两位代表、第二簇一位：代表权重为 `(1/4,1/4,1/2)`。若第一簇请求三位但只有两位，仍用这组权重，不使用 1/6。
2. 上述代表输入 Top2 分别为 `{A,B}`、`{B,C}`、`{A,C}`，票数为 A=3/4、B=1/2、C=3/4。输出 Top2 为 A、C（并列按 ID）；最终等权各 1/2。输出 Top3 且票数加权时为 `(3/8,1/4,3/8)`。
3. 三个等权代表对 A/B/C 的名次分别为 `(1,2,3)`、`(3,1,2)`、`(2,1,3)`，平均名次为 `(2,4/3,8/3)`，输出 Top2 为 B、A。若用例 1 权重，平均名次为 `(2,5/4,11/4)`，排序不变。
4. 两个等权代表排序分别为 A>B>C 和 C>B>A，平均名次全部为 2，按 ID 取 A、B。若第二代表只有 B>C，交集为 B/C；重排后名次均为 `(1,2)`，输出 B、C，不能给缺失 A 补末名。
5. 中心坐标为 0、1、3 的一维簇，总距离为 4、3、5，R1 选坐标 1，取两代表时选 1、0。RT 候选两天各选两股、分别命中 2 和 1 股，重合分数为 3/4。
6. RS 年度百分位 `(1/4,1/2,3/4)` 的中位数和样本标准差分别为 1/2、1/4，λ=1 时分数为 3/4；恒为 1/2 的候选分数为 1/2，因此后者优先。
