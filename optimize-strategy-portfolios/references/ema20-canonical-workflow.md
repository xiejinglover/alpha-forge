# EMA20 标准低 Beta 流程

## 唯一标准链路

```mermaid
flowchart LR
    A["候选正式扣费账户"] --> B["部署前三年数据"]
    B --> C["基础资格和正控制后Alpha门槛"]
    C --> D["计算残差稳健质量分"]
    D --> E["质量分降序取Top100"]
    E --> F["对家族full基准计算普通Beta"]
    F --> G["Beta升序取前N"]
    G --> H["N个候选账户按1/N线性等权"]
    H --> I["成员与权重在部署期冻结"]
    I --> J["收益、回撤、普通/控制后/下行/尾部Beta评估"]
```

`QUALITY_EQ`、稳健 Beta、残差去相关、风险簇约束和股票投票都不在这条标准链路中。

## 质量分的精确定义

在每个三年估计窗口，先以当日全候选账户等权收益作为候选家族共同成分 (c_t)。对候选 (i)：

\[
\hat\beta_i=\frac{\operatorname{Cov}(r_{i,t},c_t)}{\operatorname{Var}(c_t)},
\qquad
u_{i,t}=r_{i,t}-\hat\beta_i c_t.
\]

在全三年窗口计算：

\[
Q_i^{full}=0.60\,P(Sharpe(u_i))+0.40\,P(Pr[u_i>0]),
\]

其中 (P(·)) 是当年全候选的横截面分位。对三年内六个半年分别计算：

\[
Q_{i,h}=0.60\,P_h(Sharpe(u_{i,h}))+0.40\,P_h(Pr[u_{i,h}>0]).
\]

最终：

\[
robust\_quality\_score_i=
0.5\left(Q_i^{full}+\operatorname{median}_{h=1,\ldots,6}Q_{i,h}\right).
\]

因此，该分数同时考虑残差风险调整收益、残差正收益日占比和半年稳定性。“按估计期 Sharpe 取 Top100”与此公式不等价。

## 资格门槛

原 EMA20 口径同时检查：

1. 三年复合收益大于0；
2. 年化波动大于0；
3. 非零收益日占比大于0；
4. 候选收益对家族 full 基准和控制风格因子回归的截距大于0；
5. 六个半年中至少四个的残差 Sharpe 大于0；
6. 账户、持仓风格暴露及其他必需数据达到冻结覆盖门槛。

第4项是资格门槛；第5项是稳定性门槛。它们都不是 Top100 的最终排序字段。

## 低 Beta 选择和 N 敏感性

Top100 形成后，用同一三年窗口对家族 full 基准做带截距一元回归，按普通 Beta 升序、`candidate_id` 升序排列。

EMA20 原 N 敏感性网格为：

```text
N = 1, 3, 5, 10, 15, 20
```

各 N 使用同一排名的嵌套前缀。第 N 个配置对 N 个候选正式账户收益等权，不根据候选的股票数、票数或当期表现重分资金。

## 与股票聚合实验的边界

原研究后来另外比较了：

- N 个策略的线性袖套；
- 将 N 个策略原生 Top3 持股投票后只买总票数 Top3；
- 所有获票股票等权购买。

后两者会改变股票层资金分配，需要正式交易执行器重跑，不能与线性袖套混为一条流程。
