# 内置风险因子收益

## 用途与边界

内置 CSV 是 EMA20 风险回归使用的日频因子模拟组合收益，用于在回归中控制常见股票风格：

\[
r_{i,t}=\alpha_i+\beta_i r_{full,t}+\gamma_i^\top f_t+\epsilon_{i,t}.
\]

其中 `f_t` 是下表九列因子收益。回归截距是控制后 Alpha，`full` 的系数是控制后 Beta。CSV 不是个股暴露数据，因此不会产生“某日持仓的八维风格向量”；若要做持仓风格聚类，仍需另外取得股票级 PIT 暴露并按持仓权重聚合。

## 字段

| CSV列 | 风格含义 | 在本 Skill 中的处理 |
|---|---|---|
| `country` | 国家/市场共同成分 | 控制收益列 |
| `beta` | 市场敏感度风格 | 控制收益列 |
| `size` | 规模风格 | 控制收益列 |
| `momentum` | 动量风格 | 控制收益列 |
| `book_to_price` | 账面市值比/价值风格 | 控制收益列 |
| `residual_volatility` | 残差波动风格 | 控制收益列 |
| `liquidity` | 流动性风格 | 控制收益列 |
| `profitability` | 盈利质量风格 | 控制收益列 |
| `investment_quality` | 投资质量风格 | 控制收益列 |

这里只记录供应商字段到研究名称的映射，不声称复刻供应商未随快照提供的底层因子构造公式。

## 版本与完整性

- 数据来源：经授权导出的第三方风格因子收益。
- 日期：`2008-01-02` 至 `2026-08-31`。
- 行数：4,536；每个交易日一行；九个因子均为有限数值。
- 单位：小数形式的日简单收益。
- 排序：交易日升序。
- 版本：每个交易日取导出时最新的有效记录，并冻结为带 SHA-256 的版本化资产。

运行：

```bash
python3 scripts/validate_bundled_factor_returns.py
```

验证器检查文件名、字段顺序、大小、哈希、行数、日期边界、日期唯一且递增，以及所有收益为有限数值。

## PIT 限制

该快照保证回归只在对应 `trade_date` 使用因子收益，并通过固定截止日防止研究读取更晚交易日；但它在导出时为每个历史交易日选择最新修订记录，没有保存各部署日当时可见的历史 revision。因此：

- 可用于复现基于交易日期隔离的收益回归；
- 不能宣称是严格的历史 revision-vintage PIT 数据；
- 若供应商历史修订会实质改变结果，应从源库按历史可得时间另建版本化快照。

商业数据向授权环境之外发布或再分发前，应核对上游许可。
